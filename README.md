# Pranshi Women's Clinic – AI Healthcare Chatbot

## About the Project
This is a simple AI chatbot project built using Python and Google Gemini API. It helps users get basic information about Pranshi Women's Clinic and answers general clinic-related questions.

## Technologies Used
- Python
- Google Colab
- Google Gemini API

## Features
- Provides clinic information.
- Answers general clinic-related questions.
- Shares appointment booking details.
- Supports English, Telugu, and Hindi.

## Important Note
This chatbot provides general information only. It does not provide medical diagnosis or treatment advice.
